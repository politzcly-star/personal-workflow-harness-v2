## 成本与未验证边界

- 测试脚本不调用付费模型，也不连接生产；执行本次设计、编码与审核的 Agent 本身仍消耗 Token。未进行付费 A/B 或额外 provider 实验。
- 收尾阶段平台 Goal 累计观测为 **430095 tokens**。这是平台计数快照，不是最终 API 账单，不能推断模型计费覆盖、缓存折扣或人民币/美元费用。实际账单及可比日常任务时延 unavailable；不宣称本版已经更快、更便宜。
- 本次含中断的工作流改造不是日常需求基准。后续在正常授权任务中被动记录成本、接受率、返工、人工介入和端到端时间，再判断路线性价比；不要求 Human 维护报表。
- 实际客户端 Hook 调用、外部 API 的具体模型身份/命名角色路由、有效上下文窗口、真实签名信任根和生产链路未验证。静态配置与夹具通过不能替代这些事实。
- 自定义 clean filter、working-tree-encoding 等转换的暂存验收不由此轻量证据助手支持；保留项目配置，使用单独验证的交付路径，不陷入重试或拆除保护。
- 本次只更新规范源仓库。其他业务项目和已经运行的任务不会因源仓库变化自动采用新入口；其迁移不在本次修改范围内。
