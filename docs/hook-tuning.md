# Hook tuning
Behavior fixtures in tests/test_harness.py cover safe local mkdir/copy/redirection, placeholder schemas, direct real-secret exposure, unapproved remote/database/destructive actions and Goal scope escapes. Signed grants never bypass secret or Goal scope checks.
The harness:server-inspection comment is a classification hint, not authority. Only a narrowly recognized remote read-only command form passes; unknown syntax remains blocked. Do not confuse prose or SQL filenames with executable database commands.
No-op PreCompact/PostCompact registrations are removed; compatibility handlers remain harmless. SessionStart injects validated pointers, not transcripts. Invalid frozen contracts/scope still block affected writes. Missing, stale or unsafe progress capsules are not injected, but may be reconstructed within intact frozen scope without restarting the task.
The signed-request adapter defaults to validation only and checks the inner command against the same scope/secret rules. Offline tests exercise exact-command binding, expiry, denial and harmless temporary execution; they do not install an authority or prove live client transport.
Use minimal redacted false-positive/negative reproductions. Actual Hook invocation and approval transport need separate runtime verification; fixture success is not sandbox proof. See verification-and-guardrails.md.
