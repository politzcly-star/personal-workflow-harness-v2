# Task Brief

Use for S2+ work or whenever a short written scope prevents drift.

```text
Task ID:
Goal:
S-Level: S2 | S3 | S4
Route (only if it changes checks or guardrails):
Skill (only if it changes the job):

Non-Goals:
Allowed Files / Areas:
Forbidden Actions / Areas:

Decision Owner: root goal owner | Human
Implementation owner / delegation benefit:
Independent reviewer / risk scope:

Acceptance Checks:
-

Stop Conditions:
- material business scope or authority changes (record evidence-backed technical clarifications and continue)
- required protected action lacks concrete authority
- a required change is outside the authorized files/areas, not merely a new file inside them

Residual Risk:
```

Do not require this brief for S0/S1 or every clear S2 task. A clear implementation request covers routine implementation, checks, narrow repair, and required review.
